How I Work

My workflow is simple: understand the problem, ask questions, build a first version, test, improve, and communicate clearly along the way.

1. Understand

I start by learning what the problem is and what success looks like.

2. Plan

I break the work into small, manageable steps before building.

3. Build

I create a simple version first, then improve it through testing and feedback.

4. Communicate

I like discussing progress, explaining ideas clearly, and keeping things transparent.
